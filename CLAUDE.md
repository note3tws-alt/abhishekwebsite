# abhishekreally.com — project guide for Claude Code

Personal brand website for **Abhishek Prakash**, a Dubai-based Digital Marketing Specialist. Live at **https://abhishekreally.com**, hosted on **Netlify** (static site, deployed by uploading the build zip). Built in a claude.ai chat in November 2026 and handed over here. Read this file before making changes.

## How the project works

Everything is generated by one script from a small set of source files. Never edit files in `out/`; edit `src/` or `build.py` and rebuild.

```
python3 build.py        # Python 3 standard library only, no packages needed
```

It produces:

| Output | What it is |
|---|---|
| `out/abhishek-really-site/` | The real multi-page website (index.html, about.html, …, sitemap.xml, robots.txt, netlify.toml, img/). This is what gets deployed. |
| `out/abhishek-really-netlify.zip` | The same folder zipped with files at the top level, for Netlify drag-and-drop deploys. |
| `out/abhishek-really.html` | A single-file preview of the whole site with hash routing (`#about`, `#kannur`, …), images inlined. Was used for the claude.ai artifact preview. Not deployed. |

Preview locally: `python3 tools/serve.py` → http://localhost:8000. (Internal links are clean root-relative URLs like `/about`, so a plain `python3 -m http.server` won't resolve them; `tools/serve.py` maps `/about` → `about.html` like Netlify does.)

### Source files

| File | Role |
|---|---|
| `src/pages.html` | All page content. Each page is a `<!--PAGE:id-->…<!--/PAGE-->` block; shared pieces are `<!--PART:name-->…<!--/PART-->` blocks; plus `<!--HEADER-->` and `<!--FOOTER-->`. |
| `src/posts.py` | The six blog articles (title, SEO title, description, category, HTML body). `build.py` turns each into a page plus the blog index. |
| `src/styles.css` | All styles. Design tokens are at the top in `:root`. Later rules intentionally override earlier ones (the file grew by appending), so check the end of the file before assuming a rule is final. |
| `src/main.js` | Page behaviour: hash routing (preview only), reveal-on-scroll, hero name animation, counters, mobile menu, contact form, copy buttons. |
| `src/chat.js` | "AP Assistant" chat widget (concatenated after main.js at build time). |
| `src/brand/` | Logo SVGs, favicon/app icons, official WhatsApp glyphs (from WhatsApp's brand pack; use unmodified). |
| `src/logos/` | Client logos (supplied by Abhishek). |
| `src/photos/` | `abhishek-suit.jpg` (home hero), `abhishek-headshot.webp` (cut-out, About/Contact/chat), `tws-avatar.jpg` (@TheWorldStories avatar). |
| `build.py` | Templating, per-page SEO titles/descriptions (`TITLES`, `DESCS`), JSON-LD structured data (`LD`), sitemap, robots, netlify.toml, 404/thanks pages, zip. |
| `tools/make_icons.js` | Regenerates favicon PNGs from `src/brand/mark*.svg` (needs Playwright). |
| `tools/make_og.js` | Regenerates the 1200×630 social share card `src/brand/og-image.jpg` (needs Playwright). |
| `tools/serve.py` | Local preview server with Netlify-style clean URLs. |

### Template tokens used in pages.html / posts.py

- `href="@about"` → link to a page id (hyphens allowed, e.g. `@google-first-page`). Becomes the clean URL `/about` on the real site (matching the canonical and sitemap) and `#about` in the preview. File names come from `FILE_NAMES` in build.py (e.g. `kannur` → `/digital-marketing-kannur`). The build stops with an error on an unknown `@id`.
- `{{i:name}}` → inline SVG icon from the `P` dict in build.py.
- `{{logo:slug}}` → client logo from `src/logos/slug.png`.
- `{{photo:name}}` → photo from `src/photos/`.
- `{{brandmark}}` → the AP logo (inline SVG from `src/brand/inline.svg`).
- `{{waicon}}` → official white WhatsApp glyph.
- `{{partname}}` → a `<!--PART:partname-->` block (e.g. `{{stats}}`, `{{faq}}`, `{{clients}}`, `{{brands-marquee}}`, `{{journey-short}}`, `{{journey-full}}`, `{{expertise}}`, `{{philosophy}}`, `{{socials}}`).

### Adding things

- **New page:** add a `<!--PAGE:id-->` block, add the id to `pages` (and `FILE_NAMES` if the URL should differ), add `TITLES[id]`/`DESCS[id]`, optionally `LD[id]`, and add it to the sitemap list in build.py.
- **New blog post:** add a dict to `POSTS` in `src/posts.py`; it is picked up automatically (page, blog index, sitemap, structured data, "More articles").
- **New client logo:** put the PNG in `src/logos/`, then add a tile to the `brands-marquee` part and a cell to the `clients` part. Logos with white text go on dark plates (`plate dk` / `mq-tile dk`).

## Deploying

Current method: run `python3 build.py`, then in Netlify → the site → Deploys → drag in `out/abhishek-really-netlify.zip` (or the folder).

Better option: push this folder to a GitHub repo and connect it to the Netlify site. The root `netlify.toml` already tells Netlify to run `python3 build.py` and publish `out/abhishek-really-site`, so every push deploys automatically.

**Netlify Forms** must be enabled (Site configuration → Forms → enable form detection) for the contact form (`contact`) and chat leads (`chatbot`) to arrive. Turn on email notifications there too.

## Design system

- **Look:** clean neutrals + one lime accent. Tokens in `:root`: `--ink #0e0e10`, `--paper #fff`, `--soft #f4f4f5`, `--lime #dfff4f`, `--night #0b0b0d`. Font: Plus Jakarta Sans (Google Fonts).
- **Layout:** a 1200px framed column with hairline borders; sections are bordered `.block`s separated by `.gap` bands. Home hero is dark; philosophy block and footer are dark; the CTA band near the bottom is lime.
- **Logo:** Abhishek's own AP mark (lime slash forming the A, joined to a white P on a dark tile), recreated as SVG in `src/brand/`. The original PNG is `src/brand/logo-mark-1024.png`.
- **Motion:** blocks fade and rise into view (no blur) via IntersectionObserver; hero name letters rise in then a lime glow passes over them; achievement numbers count up; skills ticker; infinite client-logo strip; all respect `prefers-reduced-motion`.
- **AP Assistant (chat.js):** rule-based assistant (no AI backend). Answers services/results/pricing/location/content/reply-time questions, collects name → need → email/phone, posts to Netlify Forms (`chatbot`) and offers WhatsApp/email hand-off. Pops up once per visit after 10 s with a bounce, lime glow and a Web Audio chime (browsers only allow sound after the visitor has clicked/tapped).

### Gotchas (learned the hard way)

- The class `.in` is an old padding utility. The reveal animation uses `.bz` / `.is-in` — don't rename it back to `.in`.
- `[hidden]{display:none!important}` must stay at the top of styles.css; panels and the contact "sent" box rely on it.
- `.portrait` is centred with `transform: translateX(-50%)`; any animation on it must keep that transform.
- Only use real logo/brand files supplied by Abhishek (e.g. the WhatsApp glyph). Don't redraw third-party logos.

## SEO setup

- Per-page `<title>` and meta descriptions live in `TITLES` / `DESCS` in build.py (kept under ~60 / ~160 characters).
- Each page has JSON-LD: WebSite on every page, plus Person, FAQPage (only where the FAQ is visible), Service list, ProfilePage, ContactPage, CollectionPage, BreadcrumbList, BlogPosting.
- `SITE_UPDATED` in build.py drives sitemap `<lastmod>` and articles' `dateModified`. Bump it when content changes.
- Open Graph / Twitter cards use `img/og-image.jpg` (1200×630, from `tools/make_og.js`). Articles get `og:type=article` with published/modified times.
- All `<img>` tags get width/height from the real file (prevents layout shift); the home hero is preloaded with `fetchpriority=high`; client logos are lazy-loaded and were palette-compressed (~75% smaller, visually identical).
- Each article ends with "Related reading" links (`RELATED` in build.py) and "More articles" rotates, so every post and both location pages get internal links.
